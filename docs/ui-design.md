# DrawGate 界面设计方案（菜单栏 / 工具栏 / 快捷操作）

> 面向 Mywx26_v1.5_DrawGate（wxWidgets 3.3.3 + MSVC，x64 Debug）
> 参考：Altium Designer、KiCad 8、OrCAD Capture、EasyEDA、LTspice、Multisim、Logisim
> 状态：待确认后实施

---

## 1. 现有功能盘点（决定菜单里能放什么）

| 已有能力 | 代码位置 | 说明 |
|---|---|---|
| 放置 5 种逻辑门（AND/OR/NOT/NAND/XOR） | `cMain::OnEnableDrawAndGate` 等、`compoent.h` | 通过左侧按钮切换 |
| 元件选择 / 拖动 | `DrawBoard::OnMouseDown/OnMouseMove` | 有 `m_selectedGate`、`m_dragOffset` |
| 端口到端口连线（正交折线） | `DrawBoard` 的 `m_wiring`、`Wire::Draw` | 正交 L 形走线 |
| 删除选中元件（连带删线） | `DeleteSelectedGate` / `DeleteWiresForGate` | |
| 网格背景 | `DrawBoard::drawGrid` | 仅绘制，无“吸附” |
| 编辑器与画布布局 | `cMain` 的 `wxBoxSizer` | 左侧一列控件，无菜单/工具/状态栏 |

**结论**：菜单第一版应围绕「文件、编辑、视图、放置、设计」，仿真类先留占位。

## 2. 参考软件各自值得借鉴的地方

| 软件 | 借鉴点 |
|---|---|
| **Altium Designer** | 工具栏按功能分组 + 分隔线；`Space` 旋转、`Ctrl+D` 复制；属性面板（Properties）常驻右侧；状态栏显示坐标/网格 |
| **KiCad 8** | 菜单结构最标准（文件/编辑/查看/放置/工具/帮助）；`W` 连线、`R` 旋转、`E` 属性、`Home` 适应窗口；快捷键可自定义 |
| **OrCAD Capture** | 「设计」菜单承载对齐/分布/层序，符合工程习惯 |
| **EasyEDA** | 右键上下文菜单随对象变化；画布左上角浮动工具条，极简 |
| **LTspice** | 仿真菜单：运行/暂停/波形查看器；有「真值表」类比物 |
| **Multisim / Proteus** | 教学向：仪器、探针、激励源放在「放置」菜单下 |
| **Logisim** | 极简教学交互：选中即放置、`Esc` 回选择工具；适合本项目的定位 |

**取舍原则**（照抄商业软件会翻车的地方）：

- 工具栏只放**高频 8~12 个**按钮，其余进菜单（Altium 的工具栏也很克制）。
- 一级菜单 ≤ 8 个，每个菜单 ≤ 12 项，超过就用子菜单。
- 所有菜单项都显示快捷键提示，禁用项灰显而不是隐藏。

## 4. 工具栏

尺寸 24×24，扁平风格，悬停高亮，提示文字带快捷键，例如「保存 (Ctrl+S)」。分组之间用分隔线。

| 组 | 按钮 | 图标建议 | 快捷键 | 优先级 |
|---|---|---|---|---|
| 文件 | 新建 / 打开 / 保存 | 纸张、文件夹、软盘 | Ctrl+N / Ctrl+O / Ctrl+S | P0 |
| 编辑 | 撤销 / 重做 / 剪切 / 复制 / 粘贴 / 删除 | 弯箭头、剪刀、纸页、垃圾桶 | Ctrl+Z / Ctrl+Y / … / Del | P0 |
| 视图 | 放大 / 缩小 / 适应窗口 / 网格开关 / 吸附开关 | 放大镜 ±、方框、网格点、磁铁 | Ctrl+= / Ctrl+- / Home / G / S | P0 |
| **绘制** | 选择 / 连线 / 放置门 / 文字 | 箭头、折线、门符号、A | Esc / W / A / T | P0 |
| 对齐 | 左 / 中 / 右 / 上 / 中 / 下 / 等距 | 对齐线图标 | — | P1 |

**绘制组做成“互斥切换”按钮**（当前工具高亮），其余组是普通命令按钮。工具按钮的选中状态要和 `DrawBoard::m_currentTool` 双向同步——否则用快捷键切工具时工具栏会显示错。

### 4.1 左侧停靠面板（替代现在的裸控件）

```text
┌──────────────┬──────────────────────────────┐
│ 元件库        │                              │
│ [搜索框____]  │                              │
│  ├ 逻辑门     │          画布                │
│  │  AND       │      （网格 + 元件）          │
│  │  OR        │                              │
│  │  NOT ...   │                              │
│  └ 引脚/常量  │                              │
├──────────────┤                              │
│ 属性          │                              │
│ 类型: AND     │                              │
│ 标号: U1      │                              │
│ 位置: 120,80  │                              │
│ 旋转: 0°      │                              │
└──────────────┴──────────────────────────────┘
  状态栏：就绪 | 工具: 选择 | X:120 Y:80 | 缩放 100% | 网格 20 开
```

- 元件库：列表项双击 = 放置（沿用现在的 `OnLibraryItemDoubleClick`），也可拖拽到画布。
- 属性面板：选中元件时实时更新（`wxPropertyGrid` 或手写 `wxFlexGridSizer`，推荐后者，少一个依赖）。
- 面板宽度固定 240px，可用分隔条拖动（`wxSplitterWindow`）。

## 6. 状态栏

5 个分区，左对齐 + 右对齐混合：

1. **提示信息**：`就绪` / `正在画线，点击输入端口…` / `已删除 U2`
2. **当前工具**：`选择` / `连线` / `放置 AND`
3. **坐标**：`X: 120  Y: 80`（跟随鼠标，画布坐标）
4. **缩放**：`100%`
5. **网格**：`网格 20 · 吸附开`

## 7. 实施建议（分三期）

### P0 —— 骨架 + 能存能撤（约 1~2 天）

1. `cMain` 里加 `wxMenuBar` / `wxToolBar` / `wxStatusBar`，命令 ID 统一枚举（`idFileNew`…）。
2. 快捷键表：`wxAcceleratorTable` 集中注册。
3. **撤销/重做**：引入命令模式 `ICommand{ Do/Undo }`，先做 4 种：放置、移动、删除、连线；栈上限 100。
4. **文件存取**：自定义 `.dgate` 格式（推荐引入单头文件 `nlohmann/json`，或先用 `wxFileConfig` 的 INI 过渡）。要存：门类型、标号、位置、旋转、连线两端、视图缩放。
5. **缩放/平移**：`DrawBoard` 增加 `m_zoom`、`m_offset`；`OnPaint` 里用 `gc->Translate/Scale`，鼠标坐标做反变换后再做命中测试。
6. **网格吸附**：移动和放置时 `round(pos / grid) * grid`，按住 `Alt` 临时关闭。
7. 状态栏接线：`wxEVT_MOTION` 更新坐标。

> 注意：现有 `Gate::drawSelf(wxMemoryDC&)` 是先把门画到内存位图再贴到画布，**缩放后位图会糊**。改造方案：绘制改用 `wxGraphicsContext` 直接矢量绘制（`drawSelf(wxGraphicsContext&, const wxAffineMatrix2D&)`），或在内存位图尺寸上乘 `zoom` 并按需重建。前者更彻底，建议顺手改掉。

### P1 —— 好用（约 2~3 天）

- 元件库面板 + 属性面板；删除旧的一排 `wxButton`。
- 复制/粘贴/框选/全选、旋转、对齐。
- 上下文菜单。
- 导出 PNG（`wxBitmap::SaveFile` 或 `wxGraphicsContext` 渲染到位图）。

### P2 —— 加分（按需）

- 仿真 + 真值表 + 波形（教学演示最出彩）。
- 导出 SVG/PDF/网表、主题、组合、快捷键自定义。

## 9. 需要你确认的点

1. **仿真**要不要做进这一版？（真值表 + 波形会让作业演示效果明显好，但工作量约 +1 天）
2. **界面语言**：只做中文，还是中文 + 预留英文（`wxLocale` / 字符串表）？
3. **文件格式**：自己定 `.dgate`(JSON)，还是直接存/读 INI 就能交差？
4. **视觉风格**：跟着系统（浅色）即可，还是要做深色主题？
5. 旧的那排按钮是**直接删掉**，还是保留一段时间方便回退？
